# ZYLO ⚡ — Share Smarter

A campus marketplace built exclusively for IITM students.
Buy, sell, and rent items within your campus community.

## Features
- 🔐 JWT Authentication (Login / Register)
- 📦 Add, Edit, Delete item listings
- 🔍 Search and filter by category and type
- 💬 Real-time chat with sellers
- 👤 Student profile with roll number and hostel
- 📱 Fully responsive dark UI

## Tech Stack
- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas
- **Auth:** JWT + bcrypt

## Made for
IIT Madras students — rent books, sell electronics,
find furniture, and more. All within campus.
